# Security

## Reporting a vulnerability

Please report a vulnerability privately through GitHub: on the repository's **Security and quality** tab, choose **Report a vulnerability**. Do not open a public issue for it.

Say what you found, how to reproduce it and which version of Bediz and of Windows you used. You will get an answer within a week.

## Supported versions

Only the latest release gets security fixes.

## What Bediz does with your screen

Bediz sends nothing anywhere: it has no telemetry and uploads nothing by itself. Screenshots and GIFs stay on the clipboard and in the folder you save to. A check for updates asks GitHub for the latest version and sends nothing else; updates are signed, and one is installed only when its signature and version match. The log keeps warnings and errors only, with your user folder hidden and never a window title or anything captured.
