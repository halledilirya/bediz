# Security

## Reporting a vulnerability

Please report a vulnerability privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**. Do not open a public issue for it.

Say what you found, how to reproduce it and which version of Bediz and of Windows you used. You will get an answer within a week.

## Supported versions

Only the latest release gets security fixes.

## What Bediz does with your screen

Bediz sends nothing anywhere: it has no telemetry and uploads nothing by itself. Screenshots stay on the clipboard and in the folder you save to. The log keeps warnings and errors only, with your user folder hidden and never a window title or anything captured.
